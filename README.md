# Predictive Maintenance — Data Engineering Deliverable

## Running this notebook on your own machine

### 1. Prerequisites
- **MySQL Server or MariaDB installed and running locally.**
  - MySQL Community Server: https://dev.mysql.com/downloads/mysql/
  - Or MariaDB: https://mariadb.org/download/
  - During install, remember the **root password** you set.
- **Python 3.10+**

### 2. Create the database + application user
Run this once, connected as `root` (replace with your actual root login):

```
mysql -u root -p < sql\00_local_setup.sql
```

(On Windows, if `mysql` isn't recognized, use the full path, e.g.
`"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p < sql\00_local_setup.sql`,
or just open `sql/00_local_setup.sql` in MySQL Workbench connected as root and run it.)

This creates the `predictive_maintenance` database and a `pm_user` / `pm_pass123` login used by
the notebook. Change the password in `00_local_setup.sql` if you'd like a different one — just
also update it in the notebook's config cell (Section 1).

### 3. Install Python dependencies
From this project folder:

```
pip install -r requirements.txt
```

### 4. Open and run the notebook
```
jupyter notebook predictive_maintenance_data_engineering.ipynb
```
Run all cells top to bottom (**Kernel → Restart & Run All**). The notebook assumes it is opened
**from this project folder** (so it can find `data/`, `sql/`, `docs/` as relative paths). If your
Jupyter working directory differs, edit `PROJECT_ROOT` in Section 1 of the notebook.

### If you get "Access denied for user 'pm_user'"
This means step 2 wasn't run yet (or was run against a different MySQL instance than the one the
notebook is connecting to). Re-run `sql/00_local_setup.sql` against the correct server, and double
check `DB_HOST` / `DB_PORT` in the notebook's config cell match your local MySQL install
(defaults: `localhost`, `3306`).

### If you get an authentication/SSL/RSA error instead of "Access denied"
Make sure `cryptography` is installed (`pip install cryptography`) — MySQL 8's default
`caching_sha2_password` auth plugin needs it for PyMySQL to connect.
